# Validation

Validated on Windows XP SP3 x86 with an Xbox Elite Wireless Controller Series 2 over USB (`VID_045E`, `PID_0B00`, tested revision `0x0517`).

A representative final Control Center session reported:

```text
XInputErrors=0
RawErrors=0
LeftStickCoverageX=100%
LeftStickCoverageY=99%
RightStickCoverageX=100%
RightStickCoverageY=99%
LTMax=255
RTMax=255
Buttons1to10=10/10
Paddles11to14=4/4
POVDirections=8/8
RumbleCommandsOK=3
RawSource=XInputBridgeXP
```

The same controller was also tested in GTA III and GTA Vice City using GInput, with normal gameplay and vibration working.

Support claims in this repository are intentionally limited to the tested USB PID/revision and Windows XP SP3 x86 until other hardware is independently validated.
